# Гавань

Генератор паролей, который ничего не хранит. Весь код выполняется в вашем браузере — пароли никогда не покидают устройство и не попадают ни на какой сервер.

**[Открыть демо](https://phantomx490.github.io/harbor-password-generator-RU/)**

## Что делает проект

- Генерирует случайные пароли с помощью криптостойкого генератора случайных чисел (`crypto.getRandomValues`)
- Настраивает длину пароля и набор символов: строчные, заглавные, цифры, спецсимволы
- Может исключать похожие символы (`l`, `1`, `I`, `O`, `0`), чтобы пароль было легче переписать вручную
- Показывает индикатор надёжности пароля
- Копирует пароль в буфер обмена и сам очищает буфер через 30 секунд
- Предлагает готовые пресеты длины и символов под конкретные сервисы: Google, YouTube, mail.ru, ВКонтакте, Discord, Roblox, Nintendo

## Приватность

- Пароли нигде не сохраняются — ни на сервере (которого нет), ни в базе данных, ни в истории браузера
- Имена пользователей и аккаунты не запрашиваются и не связываются с созданными паролями
- Проект не отправляет никаких данных по сети — можно проверить это в исходном коде или просто отключить интернет при использовании
- Полный список правил — на самой странице, в разделе «Правила проекта»

## Как запустить

Проект — это один HTML-файл без зависимостей и сборки.

**Локально:** скачайте `index.html` и откройте его в любом браузере.

**На GitHub Pages:**
1. Загрузите `index.html` в репозиторий
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`
3. Через пару минут сайт будет доступен по ссылке `https://ваш-логин.github.io/название-репозитория/`
