# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Проект использует версионирование вида `MAJOR.MINOR.PATCH.BUILD`.

## [0.1.0.0] — 2026-08-20

Первый релиз проекта «Гавань».

### Добавлено
- Генератор паролей на стороне клиента — код выполняется только в браузере, ничего не отправляется на сервер
- Криптостойкая генерация случайных символов (`crypto.getRandomValues`)
- Настройка длины пароля (ползунок, от 6 до 48 символов)
- Выбор наборов символов: строчные, заглавные, цифры, символы
- Опция исключения похожих символов (`l`, `1`, `I`, `O`, `0`)
- Индикатор надёжности пароля на основе оценки энтропии
- Копирование пароля в буфер обмена с автоматической очисткой буфера через 30 секунд
- Пресеты требований для популярных сервисов: Google/YouTube, mail.ru, ВКонтакте, Discord, Roblox, Nintendo
- Раздел «Правила проекта» с описанием политики приватности
- Адаптивный интерфейс, тема оформления «маяк и гавань»

### Принципы
- Пароли не сохраняются нигде — ни на сервере (которого нет), ни в базе данных
- Имена пользователей не запрашиваются и не связываются с паролями
- Исходный код открыт для проверки
